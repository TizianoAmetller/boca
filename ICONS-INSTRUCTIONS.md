# 📱 Instrucciones para los Íconos

La extensión necesita 3 archivos de ícono en la carpeta `icons/`:
- `icon16.png` (16x16 píxeles)
- `icon48.png` (48x48 píxeles)
- `icon128.png` (128x128 píxeles)

## Opción 1: Generar con el HTML incluido

1. Abre `create-icons.html` en tu navegador
2. Haz clic en "Generar Todos los Íconos"
3. Descarga cada ícono
4. Colócalos en la carpeta `icons/`

## Opción 2: Crear íconos manualmente

Puedes usar cualquier editor de imágenes (Paint, GIMP, Photoshop, etc.) para crear íconos simples:

- **Color de fondo:** Azul de Boca (#004d98 o #0066cc)
- **Tema:** Pelota de fútbol, letra "B", o símbolo de entradas
- **Tamaños:** 16x16, 48x48, 128x128 píxeles

## Opción 3: Usar íconos temporales

Si solo quieres probar la extensión rápidamente:

1. Crea 3 imágenes simples (pueden ser cuadrados de color azul)
2. Nómbralos: `icon16.png`, `icon48.png`, `icon128.png`
3. Colócalos en la carpeta `icons/`

## Nota

Si no tienes íconos, la extensión funcionará igual, pero Chrome mostrará un ícono por defecto (un puzzle piece).
